CLI:

xnat-ingest group \
    <input-dir> \
    <output-dir> \
    --recursive \
    --datatype image/png \
    --datatype image/jpeg \
    --session '{subject_uid}_{CaptureDate:%Y%m%d}' all \
    --scan 'dermoscopy-{LesionID}' 'image/png|image/jpeg' \
    --resource CaptureDevice 'image/png|image/jpeg' \
    --on-resource-clash merge \
    --path-metadata-regex '.*/(?P<subject_uid>[\w-]+)/(?P<filename>[\w-]+\.(?:png|jpg))' all \
    --metadata-table <path-to-csv> 'fileset[image/png|image/jpeg]' ImagePath='=HYPERLINK("{subject_uid}/{filename}")'


ENV vars (Kubernetes container spec):
    command: ["xnat-ingest"]
    args: ["group"]
    env:
      - name: XINGEST_INPUT_PATHS
        value: "<input-dir>"
      - name: XINGEST_OUTPUT_DIR
        value: "<output-dir>"
      - name: XINGEST_RECURSIVE
        value: true
      - name: XINGEST_DATATYPES
        value: "image/png;image/jpeg"                 # ';' separates multiple values
      - name: XINGEST_SESSION
        value: '{SubjectID}_{CaptureDate:%Y%m%d} all'
      - name: XINGEST_SCAN
        value: "LesionID all"
      - name: XINGEST_RESOURCE
        value: "CaptureDevice all"
      - name: XINGEST_ON_RESOURCE_CLASH
        value: "merge"
      - name: XINGEST_PATH_METADATA_REGEX
        value: '.*/(?P<image_path>[\w-]+/[\w-]+\.(?:png|jpg)) all'
      - name: XINGEST_METADATA_TABLES
        value: '<path-to-csv> fileset ImagePath==HYPERLINK("{image_path}")'


Notes:
  - XINGEST_SESSION must be quoted: a YAML scalar starting with '{' is otherwise
    parsed as a flow mapping.
  - XINGEST_PATH_METADATA_REGEX: single-quote it so backslashes stay literal
    (a double-quoted YAML scalar would need '\\w', '\\.').
  - XINGEST_METADATA_TABLES: the '==' is literal. On the CLI the shell concatenates
    ImagePath= + '=HYPERLINK(...)'; in an env var there is no shell, so write the
    double '='. The parser splits the join expr on the first '=' (column='ImagePath',
    value='=HYPERLINK("{image_path}")').
  - Multiple values are ';'-separated. Within one value the fields are
    space-separated and only the LAST field may contain spaces, so the regex and
    the CSV path must be space-free (use '\s' in the regex if it must match a space).
  - The regex matches exactly one directory level above the file and '(?:png|jpg)'
    will not match '.jpeg' — a non-matching path is a hard error, not a skip.
  - '... all' is the datatype slot of --path-metadata-regex (any FileSet); the two
    tokens are still required.


Dexi and Whole Body Lesion Analysis CLI:

xnat-ingest group <vectra-tree> <out> \
  --recursive \
  --datatype medimage/vnd.canfield.whole-body-analysis-dir \
  --datatype medimage/vnd.canfield.dexi-data-dir \
  --ignore-path '.*' \
  --path-metadata-regex '.*/(?P<subject_uid>[\w\-]+)/(?P<CaptureDate>\d{8})(?P<CaptureTime>\d+)/analysis' medimage/vnd.canfield.whole-body-analysis-dir \
  --path-metadata-regex '.*/(?P<subject_uid>[\w\-]+)/(?P<CaptureDate>\d{8})(?P<CaptureTime>\d+)/DexiData.*' medimage/vnd.canfield.dexi-data-dir \
  --session '{subject_uid}_{CaptureDate:%Y%m%d}' all \
  --scan 'dexi-{CaptureTime}' medimage/vnd.canfield.dexi-data-dir \
  --scan 'all-lesion-analysis-{CaptureTime}' medimage/vnd.canfield.whole-body-analysis-dir


Whole Body (internal) CLI:

```
xnat-ingest group \
    <input-dir> \
    <output-dir> \
    --datatype medimage/vnd.canfield.vectra-export \
    --datatype application/vnd.sqlite3 \
    --session session_uid all \
    --path-metadata-regex '.*/(?P<session_uid>[\w-]+)' medimage/vnd.canfield.vectra-export \
    --path-metadata-regex '.*/(?P<SubjectID>[^\/_]+)_(?P<session_uid>[\w-]+)' application/vnd.sqlite3 \
    --convert medimage/vnd.canfield.vectra-export medimage/vnd.canfield.vectra-export+zip
```
